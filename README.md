## 🇪🇸 Español

Esta aplicación es un e-commerce de ropa deportiva. La idea es que los usuarios puedan comprar ropa deportiva y luego revisar su carrito de compras.

**Tecnologías**

- **Interfaz:** TypeScript · React · Redux · CSS Modules · Sass
- **Backend:** Node.js · Express.js · Sequelize · Stripe
- **Base de datos:** PostgreSQL
- **Deploy:** Heroku (backend) y Vercel (frontend)

---

## 🇬🇧 English

This application is an e-commerce store for sportswear. The idea is that users can buy sports clothes and then review their shopping cart.

**Technologies**

- **Interface:** TypeScript · React · Redux · CSS Modules · Sass
- **Backend:** Node.js · Express.js · Sequelize · Stripe
- **Database:** PostgreSQL
- **Deployment:** Heroku (backend) and Vercel (frontend)
